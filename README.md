# 🌐 Portafolio de Prácticas y Laboratorios de Redes

¡Bienvenido a mi portafolio de redes de computadoras! 🚀

Este repositorio centraliza mis laboratorios prácticos, ejercicios de configuración y escenarios de simulación sobre **telecomunicaciones, arquitectura de redes, enrutamiento, conmutación y seguridad (hardening)**.

---

### 🎯 Objetivos del Repositorio

* **Documentar** el paso a paso de configuraciones en entornos simulados y reales (Cisco IOS, Packet Tracer, GNS3).
* **Demostrar** competencias en diseño de topologías, direccionamiento IP, protocolos de red y mitigación de amenazas.
* **Servir** como guía rápida de referencia para comandos CLI, solución de problemas (*troubleshooting*) y buenas prácticas.

---

### 🛠️ Tecnologías y Protocolos

* **Simuladores:** Cisco Packet Tracer, GNS3, Wireshark.
* **Dispositivos:** Routers y Switches Cisco (IOS).
* **Conceptos:** VLANs, Trunking, Spanning Tree (STP), OSPF, BGP, SSH, Port Security, Access Control Lists (ACLs).
